# 🐙 StudyPal

An AI-powered flashcard app with a playful UI. Turn a **PDF** or a **YouTube video** into multiple-choice study cards, organise them in **nested decks**, and track your progress.

Runs fully on your machine with a local model ([Ollama](https://ollama.com)), or with [Google Gemini](https://aistudio.google.com/apikey) using your own API key.

## Features

- **Subjects with unlimited nested subdecks** (subject → subdeck → sub-subdeck → …), each with its own cards and materials
- **Path** and **Materials** views for every deck, with breadcrumb navigation
- **Import material** from a PDF or a YouTube link; cards are generated by AI into the deck you choose
- **Quiz mode** with hearts, keys, XP and confetti
  - **Hint**: removes a wrong answer
  - **Reveal**: shows the answer
  - **Explain**: *"Explain it to me like I'm 5"* or *"Go in depth"*
- **Progress tracker**: streak, XP, accuracy, 14-day activity chart and mastery per subject
- **Export / import subjects** as JSON, including all subdecks and progress
- **Choose your AI**: local Ollama or Gemini (switch any time in ⚙️)
- Dark mode, no accounts, no database

## Run locally

Requires [Node.js 18+](https://nodejs.org) and, for local AI, [Ollama](https://ollama.com).

```bash
ollama pull llama3.1:8b      # skip if you only use Gemini
npm install
npm start
```

Open http://localhost:3000.

**Windows shortcut:** double-click `local/start-studypal.bat` (starts Ollama, pulls the model if needed, and opens the app) or `local/start-studypal-gemini.bat` (no Ollama).

## Deploy to Vercel

1. Push this repo to GitHub.
2. In [Vercel](https://vercel.com/new), import the repository.
3. Leave the framework preset as **Other** and deploy. No build command or environment variables are needed.

Vercel serves `public/` as the site and `api/` as serverless functions.

### Choosing an AI on the hosted site

The first time you open the site, ⚙️ settings will ask which AI to use.

**Gemini (easiest):** pick *Google Gemini*, paste your API key and save. The key is stored only in your browser and is sent to Google through the `/api/chat` function. It is never stored on the server. If you get a "model not found" error, replace the model name in settings with the current Flash model shown in [AI Studio](https://aistudio.google.com).

**Ollama:** a website cannot start Ollama for you, so the browser talks directly to Ollama on your own computer. Allow your site's address, then restart Ollama:

| OS | Command |
| --- | --- |
| Windows | Add a user environment variable `OLLAMA_ORIGINS` = `https://your-app.vercel.app`, then restart Ollama |
| macOS | `launchctl setenv OLLAMA_ORIGINS "https://your-app.vercel.app"`, then restart Ollama |
| Linux | `sudo systemctl edit ollama` → add `Environment="OLLAMA_ORIGINS=https://your-app.vercel.app"`, then `sudo systemctl restart ollama` |

Chrome and Edge may ask permission to access local devices. Safari blocks this, so use Chrome, Edge or Firefox, or run the app locally.

## Project structure

```
public/index.html     The whole front end (HTML, CSS, JS)
api/chat.js           Serverless proxy for Gemini
api/yt.js             Serverless YouTube transcript fetcher
local/server.js       Local server for `npm start`
local/*.bat           Windows launchers
vercel.json           Function settings
```

## Data and privacy

- Decks, cards and progress are stored in your browser's `localStorage`. Use **📤 Export** on a subject for backups or to move it to another device. Clearing browser data erases your decks.
- With Ollama, your material never leaves your computer. With Gemini, the text is sent to Google.

## Limitations

- Each upload uses roughly the first 30,000 characters of the source (up to about 48 cards). Use several subdecks or uploads for long documents.
- YouTube import needs a video with captions. YouTube often blocks requests from cloud servers, so import may fail on the hosted site. It is more reliable when running locally.
- Scanned PDFs without selectable text are not supported.
- Card quality depends on the model. Larger models give better questions.

## Tech

Vanilla JS front end, [pdf.js](https://mozilla.github.io/pdf.js/) for PDFs, [youtube-transcript](https://www.npmjs.com/package/youtube-transcript) for captions, Vercel serverless functions.
